# Software Development & Workflow Orchestration

- Lead developer of [Funnel](https://github.com/calypr/funnel), a workflow orchestration toolkit that executes genomic analysis tasks across cloud and HPC environments through a standard task-execution API, enabling scalable, autonomous data processing for research pipelines.
- Wrote the [Kubernetes](https://kubernetes.io/) deployment templates ([Helm](https://helm.sh/) charts) used to deploy the lab's data commons and analysis services into production.
- Built a [Nextflow](https://www.nextflow.io/) plugin integrating the [GA4GH Task Execution API](https://github.com/ga4gh/task-execution-schemas), allowing existing genomic workflows to run against multiple execution backends without rewriting pipeline code.
- Contributed to [Gen3-Workflow](https://github.com/uc-cdis/gen3-workflow), the workflow execution service used by the Gen3 data commons platform to run researcher-submitted analysis jobs.

# Cloud Infrastructure & DevOps

- Built and scaled cloud-native infrastructure and CI/CD systems across [AWS](https://aws.amazon.com/), [Azure](https://azure.microsoft.com/), and [OpenStack](https://www.openstack.org/), including automated service provisioning and backup/restore procedures.
- Deployed status monitors and a real-time dashboards for tracking the system health and availability of the lab's services.
- Helped develop the [DRS Downloader](https://github.com/ga4gh/drs-downloader), a data transfer tool implementing the GA4GH Data Repository Service standard to move data between cloud storage systems and local research environments.
