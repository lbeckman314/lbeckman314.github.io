# FHIR-Aggregator Client

An [HL7 FHIR](https://hl7.org/fhir/) client for the NIH Cloud Platform Interoperability program, using GraphDefinition-driven traversals to query and locally analyze interconnected clinical and genomic data hosted on Google's Cloud Healthcare API.
