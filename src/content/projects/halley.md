A tiny live countdown to Halley's Comet's next perihelion — [July 28, 2061](https://wikipedia.org/wiki/Halley%27s_Comet).

**[halley.liambeckman.com](https://halley.liambeckman.com)**

The comet last passed by Earth in 1986 and won't be back for another 75-ish years, so this counts down the years, days, hours, minutes, and seconds until then.

## Getting started

Built with [Create React App](https://github.com/facebook/create-react-app). Install [Node](https://nodejs.org/) LTS, then:

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it.

```sh
npm run build
```

builds a production bundle to `build/`.
