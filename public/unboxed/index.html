What's in the box

      
The kernel runs at WebAssembly speed. Only the programs on top are emulated.

    

    

      
Your toolNeovim, ripgrep, Python… unmodified Alpine packages

      
Alpine Linux 3.24aarch64 user space, with apk and BusyBox

      
kwemuan aarch64 CPU with a JIT that compiles hot code to WebAssembly

      
Linux 7.x kernelcompiled to WebAssembly, with a real MMU: fork, mmap, signals and /proc behave as on a server

      
Your browser tabChrome, Edge, Firefox or Safari, on a laptop or a phone

    

    
Built on unkernel. The tools install from Alpine's signed packages, hosted next to this page.

  






  

    
Questions

    

      

        Does anything run on a server?
        
No. The kernel, the emulated CPU and your programs all run in your browser tab. The page downloads about 10 MB, plus each tool's packages when you open it.

      

      

        Can programs reach the internet?
        
Not by default. Browsers can't open raw TCP sockets, so internet access goes through a Wisp proxy you can set in the playground's options. Every tool on the shelf works without one.

      

      

        Which programs can run?
        
Anything built for 64-bit ARM Linux, which covers Alpine's and Debian's package archives. x86-only binaries won't run, and CPU-heavy work is well behind native speed.

      

      

        Which browsers work?
        
Chrome and Edge 137 or later, Firefox 153 or later, and Safari 27 or later, including on phones. Older browsers lack a WebAssembly feature the kernel needs, and the playground says so.

      

      

        What happens to my changes?
        
They live in memory and vanish when you close the tab, so you can't break anything.
