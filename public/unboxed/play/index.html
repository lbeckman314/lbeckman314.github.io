About Playground

Playground

Try popular command-line tools and GitHub repositories in unkernel, a real Linux kernel compiled to WebAssembly. Everything runs in this tab, on your device.

Try a tool

Or any public repository

Options

Tools are installed from a small set of Alpine Linux packages served with this page (sudo apk add works for those without any network). A repository is copied to ~/<repo>; if it has a .unkernel.sh at its root, that script runs first, so a project can set up its own demo: 

#!/bin/sh
# .unkernel.sh: runs in the repo's directory when someone opens it here
sudo apk add python3
python3 demo.py

For anything beyond the hosted packages, the guest needs the internet, which a browser can only reach through a Wisp proxy (Options). Changes vanish when you leave the page.
