Repo Playground

Enter a public GitHub repository and run it in unkernel, a real Linux kernel compiled to WebAssembly. Everything runs in this tab, on your device.

Options

The repository is copied to ~/<repo> in an Alpine Linux guest (aarch64 user space). If it has a .unkernel.sh at its root, that script runs first, so a project can set up its own demo: 

#!/bin/sh
# .unkernel.sh: runs in the repo's directory when someone opens it here
sudo apk add python3        # needs a network (a Wisp proxy)
python3 demo.py

Without a Wisp proxy the guest has no network, so only what Alpine's base image carries (BusyBox and a POSIX shell) is available. Changes vanish when you leave the page.
